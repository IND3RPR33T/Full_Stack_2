# Global Context Counter

A Futuristic React Application demonstrating the power of the Context API for global state management.

## 🚀 Overview

This project implements a global counter using React's `createContext` and `useContext` hooks. It features a modern, neon-themed UI with glassmorphism effects and smooth animations.

## ✨ Features

- **Global State Management**: Uses `GlobalContext` to share state across components without prop drilling.
- **Futuristic UI**: Custom CSS with neon glow effects, glassmorphism, and 3D card tilts.
- **Interactive Counter**: Increment and decrement functionality powered by a global provider.
- **Responsive Design**: Adapts seamlessly to different screen sizes.

## 🛠️ Tech Stack

- **React** (v18+)
- **Vite**
- **CSS3** (Custom Properties, Flexbox, Animations)
